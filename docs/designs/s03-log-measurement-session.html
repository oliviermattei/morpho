Maquette de référence — s03 · Saisir une session de mesures

Référence visuelle, pas du code de production. L'implémentation reconstruit ces écrans avec les composants générés dans src/components/ui/ : field, input, button, item, empty, skeleton, spinner, sonner.

Chaque cadre fait 375 px de large — la cible iOS Safari en portrait. Le thème suit prefers-color-scheme : basculer le réglage du système bascule toute la page. Toutes les couleurs et tous les rayons viennent des tokens de src/app/globals.css.

Les bornes chiffrées des messages d'erreur sont des exemples : les plages physiologiques réelles par mesure sont une décision du Plan.
